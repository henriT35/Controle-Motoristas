PAINEL MOTORISTAS v0.6.0.3

CORRECAO PRIORITARIA — WHATSAPP / QR / BANCO DO NAVEGADOR
=========================================================

Esta versao corrige o ciclo em que o WhatsApp Web pede para reconectar, informa erro no banco de dados do navegador e nao chega a um QR utilizavel.

DEPOIS DE ATUALIZAR UMA INSTALACAO COM O BUG:
1. Inicie o Painel normalmente (local ou online).
2. Abra WhatsApp Motoristas.
3. Clique Redefinir sessao UMA VEZ para remover/isolar o profile antigo corrompido.
4. Clique Conectar WhatsApp.
5. Aguarde o QR aparecer no Painel ou na janela do WhatsApp Web.

O bot tambem detecta automaticamente a mensagem de banco de dados corrompido do WhatsApp Web e tenta reconstruir o profile uma vez.

MODO ONLINE SEM DOMINIO
========================
Use EXECUTAR_ONLINE.bat para criar a URL temporaria https://...trycloudflare.com.
ABRIR_LINK_ONLINE.bat reabre/copia a URL.
PARAR_ONLINE.bat encerra Painel + tunel.
