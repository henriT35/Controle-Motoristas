PAINEL MOTORISTAS — PATCH v0.6.0.0

BASE OBRIGATÓRIA: v0.5.0.1

1. Faça backup do banco/local_data da instalação atual.
2. Feche o Painel e o Bot WhatsApp, se estiverem abertos.
3. Extraia este patch sobre a pasta do Painel v0.5.0.1, preservando a estrutura e substituindo arquivos existentes.
4. Abra EXECUTAR_LOCAL.bat e deixe a etapa de makemigrations/migrate terminar.
5. Para usar o WhatsApp Bot, execute INSTALAR_BOT_WHATSAPP.bat uma vez.
6. Configure PANEL_PUBLIC_BASE_URL no .env com uma URL que o celular do motorista consiga abrir.
   Ex.: https://painel.suaempresa.com.br
7. Abra WhatsApp Motoristas no menu, conecte o WhatsApp Web e teste com UM motorista antes do lote.
8. Rode VERIFICAR_BUILD.bat na instalação real.

IMPORTANTE:
- O bot é auxiliar e pode solicitar QR novamente.
- O Painel/Portal funcionam sem o bot.
- O core robot_ssw homologado não foi alterado.
