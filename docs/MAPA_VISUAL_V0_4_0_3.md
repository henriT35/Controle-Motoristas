# Mapa Operacional — Polimento visual V2 (v0.4.0.3)

Escopo exclusivamente visual/UX.

- mapa ocupa mais a área útil do card;
- hierarquia de labels em três níveis (nome+valor, somente valor, hover);
- regiões sem movimento mais discretas;
- paleta low-profile refinada;
- tooltip, legenda, ranking e alertas reequilibrados;
- mapa ganhou protagonismo com lateral visualmente mais contida;
- microinterações e transições foram reduzidas a efeitos discretos.

Nenhuma regra de negócio, consulta, modelo, migration, Import Engine ou robot_ssw foi alterado.
