PAINEL MOTORISTAS v0.6.0.3 — ONLINE + WHATSAPP QR/SESSAO

MODO ONLINE SEM DOMINIO
-----------------------
1) Execute EXECUTAR_ONLINE.bat.
2) O launcher baixa/detecta o cloudflared, cria uma URL https://*.trycloudflare.com e abre o Painel.
3) A URL fica salva em local_data\online_url.txt. Para abrir/copiar novamente, use ABRIR_LINK_ONLINE.bat.
4) Para encerrar Painel + tunel, use PARAR_ONLINE.bat.
5) Se a senha admin ainda for Painel@2026!, ela será substituida automaticamente antes da primeira publicacao; consulte local_data\ONLINE_ADMIN.txt.

IMPORTANTE: a URL do Quick Tunnel e temporaria e muda quando o tunel for recriado.


WHATSAPP — PRIMEIRA ABERTURA APOS v0.6.0.3
--------------------------------------------
Se a versao anterior ficou presa em "reconectar" / "erro no banco de dados do navegador":
1) Abra WhatsApp Motoristas.
2) Clique Redefinir sessao uma vez.
3) Clique Conectar WhatsApp.
4) Escaneie o QR novo.

A v0.6.0.3 detecta e reconstrói automaticamente uma sessao/IndexedDB corrompida uma vez.

MODO LOCAL
----------
Use EXECUTAR_LOCAL.bat quando nao quiser acesso pela Internet.

V0.3.0.4 - ANTES DO PRIMEIRO USO DO ROBO
------------------------------------------
Execute TESTAR_RESILIENCIA_SSW_V0_3_0_4.bat.
Se a fila estiver pausada, consulte /ssw/importacoes/ ou execute:
  python manage.py ssw_queue_control status
O retry de erro deve ser feito pelo botao "Reprocessar somente esta janela" no Historico.
