`manage.py check` não pôde ser executado neste ambiente porque Django não está instalado e o runtime não possui acesso ao PyPI para instalar dependências. Isso não foi classificado como falha do projeto.

No Windows de homologação, executar:

```text
TESTAR_RESILIENCIA_SSW_V0_3_0_4.bat
```

## Testes reais obrigatórios no Windows/SSW

1. execução normal da opção 036;
2. confirmar `DOWNLOADED → Validação → SUCCESS/WARNING`;
3. simular indisponibilidade/lentidão além do timeout;
4. confirmar job `ERROR` e fila `PAUSADA`;
5. confirmar que as outras janelas ficaram `QUEUED`;
6. confirmar botão **Baixar diagnóstico técnico**;
7. confirmar botão **Reprocessar somente esta janela**;
8. confirmar que o retry roda antes das demais janelas pendentes;
9. confirmar **Retomar fila**;
10. reiniciar/derrubar worker em uma execução de teste e validar `ORPHAN_RUNNING_JOB`;
11. confirmar que nenhuma janela `SUCCESS/WARNING` anterior foi recriada.
