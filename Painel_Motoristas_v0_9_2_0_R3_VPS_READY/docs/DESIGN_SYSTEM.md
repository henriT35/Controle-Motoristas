# Design System

Referência visual: `docs/mockups/`.

- Desktop-first, referência 1672x941, 16:9.
- Sidebar 244px.
- Inter como tipografia-alvo; fallback system-ui.
- Lucide para ícones.
- Apache ECharts para gráficos.
- Tokens principais definidos em `static/css/app.css`.
- Status: azul informação, verde concluído, amarelo atenção, vermelho crítico, roxo oportunidade, ciano SSW/sync.
